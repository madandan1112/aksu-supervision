# 部署手册（生产环境）

> 适用：单机 Linux（推荐 4C8G+，系统盘外挂数据盘）。
> 组件：JDK17、MySQL 8、Redis、MinIO、Nginx、后端 JAR、三个前端静态产物。

## 一、服务器初始化

```bash
# JDK 17
apt install -y openjdk-17-jdk
# MySQL 8 / Redis
apt install -y mysql-server redis-server
# MinIO（官方二进制）
wget https://dl.min.io/server/minio/linux-amd64/minio -O /usr/local/bin/minio && chmod +x /usr/local/bin/minio
useradd -r minio-user && mkdir -p /data/minio && chown minio-user /data/minio
```

MinIO systemd（/etc/systemd/system/minio.service）：

```ini
[Unit]
Description=MinIO
After=network.target
[Service]
User=minio-user
Environment="MINIO_ROOT_USER=<强用户名>"
Environment="MINIO_ROOT_PASSWORD=<强密码>"
ExecStart=/usr/local/bin/minio server /data/minio --address :9000 --console-address :9001
[Install]
WantedBy=multi-user.target
```

## 二、数据库

```bash
mysql -e "CREATE DATABASE aksu_supervision DEFAULT CHARACTER SET utf8mb4;"
mysql aksu_supervision < db_v8_chinese.sql        # 基础结构+种子
mysql aksu_supervision < insert_bureaus.sql       # 组织树
mysql aksu_supervision < townships_insert_fixed.sql  # 94 乡镇街道
mysql aksu_supervision < scripts/fix_data_permission_chain.sql
# 每日备份（cron）
echo '0 3 * * * mysqldump -u<user> -p<pwd> aksu_supervision | gzip > /data/backup/aksu_$(date +\%F).sql.gz' | crontab -
```

## 三、后端

```bash
# /etc/systemd/system/aksu-backend.service
[Unit]
Description=Aksu Supervision Backend
After=mysql.service redis-server.service
[Service]
Environment=DB_PASSWORD=<强密码>
Environment=JWT_SECRET=<至少256位强随机串>
Environment=CAPTCHA_LOG_CODE=false
Environment=WX_MINI_APPID=<小程序appid>
Environment=WX_MINI_SECRET=<小程序secret>
Environment=WX_TPL_RECTIFY=<整改通知订阅模板ID，可空>
Environment=WX_TPL_ALERT=<预警订阅模板ID，可空>
Environment=BAIDU_OCR_APP_ID=/BAIDU_OCR_API_KEY=/BAIDU_OCR_SECRET_KEY=<可空，降级手动录入>
Environment=SPRING_PROFILES_ACTIVE=prod
ExecStart=/usr/bin/java -Xms1g -Xmx2g -jar /opt/aksu/aksu-supervision-backend-1.0.0.jar
SuccessExitStatus=143
[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now aksu-backend
```

## 四、前端静态部署

```bash
cd web-admin   && npm ci && npm run build    # dist/ → /opt/aksu/web-admin
cd miniapp-h5  && npm ci && npm run build    # dist/ → /opt/aksu/miniapp-h5
```

Nginx（/etc/nginx/sites-available/aksu.conf）：

```nginx
server {
    listen 443 ssl http2;
    server_name aksu.example.gov.cn;          # 备案域名
    ssl_certificate     /etc/nginx/ssl/aksu.pem;
    ssl_certificate_key /etc/nginx/ssl/aksu.key;

    # 管理后台
    location / { root /opt/aksu/web-admin; try_files $uri $uri/ /index.html; }
    # 小程序 H5
    location /h5/ { alias /opt/aksu/miniapp-h5/; try_files $uri $uri/ /h5/index.html; }
    # 公众扫码公示（打在企业二维码上的地址）
    location /public/ { alias /opt/aksu/miniapp-h5/; try_files $uri /public/index.html; }
    # API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        client_max_body_size 20m;
    }
}
```

> 企业二维码内容格式：`https://<域名>/public/credit/<统一信用代码>`（web-admin 企业列表"监管码"自动生成）。

## 五、微信小程序发布

1. `miniapp/src/manifest.json` 填入 appid；`src/utils/request.js` 的非 H5 `BASE_URL` 改为 `https://<域名>/api`。
2. `cd miniapp && npm run build:mp-weixin`，微信开发者工具导入 `dist/build/mp-weixin`。
3. 平台配置"服务器域名"→ request 合法域名 `https://<域名>`（须 ICP 备案）。
4. 真机自测（扫码/拍照上传/GPS）→ 上传体验版 → 提交审核。
